## Data notes

_The page computes its figures from data/college_town_home_sales.csv, excluding the four sales below $1,000 because the data description flags them as implausible. It keeps higher-priced sales, repeated addresses, and rows with missing property details; it doesn’t use the unreliable home_type field. The town count is the number of distinct city and state pairs. The qualifying sale count is the number of rows priced at least $1,000. The overall median uses all qualifying sales; each town’s median uses that town’s qualifying sales, averaging the two middle prices when the count is even. The chart and table display medians rounded to whole US dollars. Towns are ranked by median, highest first, with ties alphabetized by city. Each town’s sales count is its number of qualifying rows. Source values are as reported by the collection source and have not been verified against county records._
